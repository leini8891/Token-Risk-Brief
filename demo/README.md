# Token Risk Brief demo recording

1. Open `index.html` in Google Chrome.
2. Press `Command + Shift + 5`.
3. Choose **Record Entire Screen**.
4. Start recording.
5. Click **Start demo**.
6. Wait until the presentation returns to **Demo complete**.
7. Stop recording from the macOS menu bar.
8. Upload the resulting `.mov` file to HackQuest under **Project Demo**.

The presentation lasts 57 seconds and contains no audio. The captions carry the
complete product story.
